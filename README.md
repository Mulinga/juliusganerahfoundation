# Julius Ganerah Foundation

Official website for Julius Ganerah Foundation, supporting access to education and healthcare in Shinyalu Constituency, Kakamega County, Kenya.

## Website
This repository contains the static HTML, CSS and JavaScript website. GitHub Pages can serve it directly from the `gh-pages` branch.

## Local preview
Open `index.html` in a browser, or use VS Code Live Server.

## Before launch
Replace the placeholder contact email in `index.html` and `script.js` with a verified inbox. The beneficiary enquiry form uses `mailto:` and does not store submissions. Do not publish children's images/video without appropriate permission.
