# Julius Ganerah Foundation Website

A responsive static website built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP folder.
2. Open `index.html` in a modern browser.
3. For the best local preview, use VS Code with the Live Server extension and select **Open with Live Server**.

No Node.js, build process or database is required.

## Upload to hosting
Upload the contents of this folder (including `assets/`, `index.html`, `styles.css` and `script.js`) into the domain's document root, commonly `public_html/` in cPanel.

## Before publishing — important customisation
- The contact email `hello@juliusganerahfoundation.org` is a placeholder. Replace it in `index.html` with an email address that has been created and verified.
- Add verified phone, WhatsApp, postal address and social links if desired.
- Confirm the foundation's legal/registration details and any programme descriptions before publishing.
- Add consent/permission for identifiable children in photographs and video, especially for public website use. Consider blurring children's faces where consent is not documented.
- The contact links currently open the visitor's email application. They are not a server-backed contact form.
- No donation/payment collection is configured. Add a verified, secure payment provider only after the foundation has an authorised account.
- The leadership section is factual and non-electoral; it does not contain campaign messaging.

## Domain
After registering `rescueshinyalu.org`, point its DNS records to the hosting provider and enable SSL/HTTPS through the host's control panel.

## Files
- `index.html` — page content and sections
- `styles.css` — responsive visual styling
- `script.js` — mobile navigation, gallery lightbox and current year
- `assets/` — logo, photographs and outreach video
